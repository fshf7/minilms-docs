MiniLMS API (1.0.0)

Download OpenAPI specification:Download

MiniLMS Team: support@minilms.local

Спецификация REST API платформы MiniLMS — системы для создания мини-курсов, назначения их группам пользователей и отслеживания прогресса прохождения.

API покрывает экраны и сценарии:

  • Слушатель: список назначенных курсов, прохождение уроков, сдача тестов
  • Автор: создание и редактирование курсов, уроков, тестов, публикация
  • Координатор: управление группами, назначение курсов, просмотр отчётов

Все защищённые эндпоинты требуют Bearer-токен в заголовке Authorization. Права доступа определяются ролью пользователя (RBAC).
