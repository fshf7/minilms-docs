## Переменные окружения

| Переменная | Описание | Обязательна | Пример |
|------------|----------|:-----------:|--------|
| `DATABASE_URL` | Строка подключения к БД | Да | `postgres://user:pass@host:5432/minilms` |
| `JWT_SECRET` | Секретный ключ для JWT | Да | — |
| `FILE_STORAGE_PATH` | Путь к директории вложений | Да | `/var/data/uploads` |
| `PORT` | Порт API | Нет | `3000` |

3. Настроить переменные окружения.
4. Применить миграции БД.
5. Запустить приложение.
6. Проверить healthcheck.
