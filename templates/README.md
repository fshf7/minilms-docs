# Шаблоны артефактов

Шаблоны для создания новых документов в проекте. Скопируйте нужный шаблон в соответствующую папку `docs/` и заполните.

| Шаблон | Когда использовать |
|--------|--------------------|
| [ADR](adr-template.md) | Фиксация принятого архитектурного решения |
| [RFC](rfc-template.md) | Предложение решения для обсуждения с командой |
| [Алгоритм](algorithm-template.md) | Описание бизнес-логики или алгоритма обработки |
| [Развёртывание](deployment-template.md) | Инструкция по деплою и настройке окружения |
