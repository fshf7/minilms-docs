# MiniLMS — Техническая документация

MiniLMS — веб-система для создания мини-курсов, назначения их группам
и отслеживания прогресса в одном месте.

## Разделы

- **Требования** — концепция продукта, функциональные и нефункциональные требования
- **Архитектура** — хранение данных, ERD, асинхронное взаимодействие, платформизация
- **Модель данных** — ERD, концептуальная и логическая модели, все сущности
- **UI / Wireframes** — макеты экранов, карта роутов, привязка к API
- **API** — OpenAPI-спецификация REST API (интерактивная)
- **Диаграммы** — sequence-диаграммы ключевых сценариев
