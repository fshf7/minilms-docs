# Нефункциональные требования — MiniLMS

## Производительность

| ID | Требование | Приоритет |
|----|-----------|-----------|
| NFR-PERF-01 | Время ответа API ≤ 500 мс (p95) при штатной нагрузке | H |
| NFR-PERF-02 | Отчёт по группе (до 50 чел.) формируется за ≤ 0.5 сек | H |

## Ёмкость

| ID | Требование | Приоритет |
|----|-----------|-----------|
| NFR-CAP-01 | До 1 000 пользователей, 300 активных/нед, 100 курсов, 10 000 попыток/мес | H |

## Безопасность

| ID | Требование | Приоритет |
|----|-----------|-----------|
| NFR-SEC-01 | Аутентификация по JWT; пароли хранятся как bcrypt-хэш | H |
| NFR-SEC-02 | Авторизация по ролям (RBAC): learner / author / coordinator / admin | H |
| NFR-SEC-03 | Защита от OWASP Top-10 (XSS, CSRF, SQL injection) | H |
