# Функциональные требования

## UC-01 — Вход в систему

- **Акторы:** Пользователь (Учащийся / Автор / Координатор / Админ)
- **Предусловия:** пользователь зарегистрирован; аккаунт активен.

**Основной поток:**

1. Пользователь открывает страницу входа.
2. Вводит email и пароль.
3. Система валидирует формат и проверяет учётные данные.
4. Система создаёт сессию и открывает главную страницу по роли.

**Постусловия:** пользователь авторизован; доступы определены ролью.

**Альтернативные потоки:**
- A1 (шаг 3): неверный пароль → ошибка, вход не выполнен.
- A2 (шаг 3): аккаунт заблокирован → отказ во входе, сообщение причины.

**Исключительные потоки:**
- E1 (шаг 3): сервис авторизации недоступен → «попробуйте позже», вход не выполнен.

**Бизнес-правила:** права доступа определяются ролью (RBAC).

## UC-02 — Создание курса (черновик)

- **Акторы:** Автор
- **Предусловия:** автор вошёл в систему.

**Основной поток:**

1. Автор выбирает «Создать курс».
2. Вводит название, описание (опц.), категорию (опц.).
3. Система создаёт курс в статусе **Черновик**.
4. Система открывает редактор курса.

**Постусловия:** курс создан и доступен автору для редактирования.

**Альтернативные потоки:**
- A1 (шаг 2): название пустое/слишком длинное → подсказка, создание запрещено.

**Исключительные потоки:**
- E1 (шаг 3): ошибка сохранения (БД недоступна) → курс не создан, сообщение об ошибке.

**Бизнес-правила:** черновик нельзя назначать учащимся/группам.

## UC-03 — Добавление урока в курс

- **Акторы:** Автор
- **Предусловия:** есть курс (Черновик или Опубликован); автор — владелец курса.

**Основной поток:**

1. Автор открывает курс и выбирает «Добавить урок».
2. Указывает название урока.
3. Добавляет контент: текст, ссылки, вложения (файлы).
4. (Опц.) Меняет порядок уроков в программе.
5. Нажимает «Сохранить».
6. Система сохраняет урок и показывает его в программе курса.

**Постусловия:** урок создан/обновлён и виден в программе курса.

**Альтернативные потоки:**
- A1 (шаг 3): файл превышает лимит → файл отклонён, урок сохраняется без этого файла.
- A2 (шаг 5): автор отменил сохранение → изменения не применяются.

**Исключительные потоки:**
- E1 (шаг 3/5): пропал интернет/ошибка бэка → ошибка, данные урока остаются на форме.

**Бизнес-правила:** «пустой урок» допускается, но при публикации курса система предупреждает о пустых уроках.

## UC-04 — Создание теста к уроку (автопроверка)

- **Акторы:** Автор
- **Предусловия:** есть урок в курсе; у урока ещё нет теста (1 тест на 1 урок).

**Основной поток:**

1. Автор открывает урок и выбирает «Добавить тест».
2. Задаёт проходной балл и (опц.) максимум попыток.
3. Добавляет вопросы: тип (один ответ / несколько / короткий текст), текст, баллы, варианты.
4. Нажимает «Сохранить тест».
5. Система сохраняет тест и привязывает к уроку.

**Постусловия:** тест создан и привязан к уроку.

**Бизнес-правила:**
- Один урок — один тест.
- Типы вопросов: single_choice, multiple_choice, short_text.

## UC-05 — Публикация курса

- **Акторы:** Автор
- **Предусловия:** курс в статусе Черновик; автор — владелец.

**Основной поток:**

1. Автор нажимает «Опубликовать».
2. Система проверяет: есть хотя бы 1 урок.
3. Система меняет статус на **Опубликован**.
4. Курс становится доступен для назначения.

**Альтернативные потоки:**
- A1 (шаг 2): нет уроков → публикация запрещена, сообщение.
- A2: система предупреждает о пустых уроках (без теста/контента), но разрешает публикацию.

---

## UC-06 — Назначение курса группе

- **Акторы:** Координатор
- **Предусловия:** курс опубликован; группа существует и содержит участников.

**Основной поток:**

1. Координатор открывает форму назначения.
2. Выбирает курс и группу.
3. (Опц.) Указывает дату старта и дедлайн.
4. Подтверждает назначение.
5. Система создаёт назначение для каждого участника группы.
6. Система отправляет уведомления о назначении.

**Постусловия:** у всех участников группы появился курс в «Мои курсы».

**Альтернативные потоки:**
- A1 (шаг 5): часть пользователей уже назначена → пропуск дублей, информация «N создано, M уже существовало».

**Бизнес-правила:**
- Дедлайн не может быть раньше даты старта.
- Назначение идемпотентно (повторное назначение не создаёт дубликат).
- Если дедлайн прошёл, а курс не завершён → статус «Просрочен».

## UC-07 — Прохождение урока и теста

- **Акторы:** Слушатель
- **Предусловия:** курс назначен слушателю; статус назначения — в процессе.

**Основной поток:**

1. Слушатель открывает «Мои курсы».
2. Выбирает курс, открывает урок.
3. Изучает материал, отмечает урок пройденным.
4. Если к уроку есть тест — открывает тест.
5. Отвечает на вопросы.
6. Нажимает «Отправить».
7. Система проверяет ответы, считает балл, определяет passed/failed.
8. Показывает результат.

**Постусловия:** попытка зафиксирована; прогресс обновлён.

**Бизнес-правила:**
- Если дедлайн прошёл, а курс не завершён → статус «Просрочен».
- Повторная отправка после таймаута не создаёт дубликат попытки (idempotency).
- Попытка неизменяема после создания (NFR-DATA-02).

## UC-08 — Просмотр отчёта по курсу/группе

- **Акторы:** Координатор (или Админ), Автор (только по своим курсам)
- **Предусловия:** есть назначения; у актора есть право на отчёт.

**Основной поток:**

1. Актор открывает «Отчёты».
2. Выбирает курс и группу.
3. Система показывает список пользователей и статусы (назначен / в процессе / завершён / просрочен) с пагинацией по 50 строк.
4. Система показывает агрегаты: сколько начали, завершили, просрочили.
5. (Опц.) Актор применяет фильтр по статусу.

**Бизнес-правила:**
- Автор видит отчёты только по своим курсам.
- Координатор — по своим группам.
- Админ — всё.

## UC-09 — Внутрисистемные уведомления

- **Акторы:** Система, Слушатель, Координатор
- **Предусловия:** создано назначение курса; (опц.) задан дедлайн.

**Типы уведомлений:**
- Назначение курса → слушателю.
- Напоминание о дедлайне (за N дней) → слушателю.
- Просрочка → слушателю и координатору.

**Основной поток:**

1. Система генерирует уведомление по событию (назначение / приближение дедлайна / просрочка).
2. Уведомление сохраняется в БД.
3. Слушатель видит уведомление в ленте.
4. Слушатель может отметить как прочитанное.
