# Changelog

Все значимые изменения в документации проекта MiniLMS.

## [1.0.0] — 2026-05-03

### Добавлено

- Структура технической документации (Docs as Code)
- Функциональные требования: UC-01 … UC-09
- Нефункциональные требования: безопасность, производительность, надёжность, UX, данные
- Стейкхолдеры и RACI-матрица
- Обзор архитектуры (шаблон)
- Хранение данных: обоснование PostgreSQL, оценка объёмов
- OpenAPI-спецификация (v1.0.0)
- Обзор API-эндпоинтов с привязкой к UC
- ERD: концептуальная и логическая модели (13 сущностей)
- Use Case диаграмма (PlantUML)
- Sequence-диаграмма UC-06: назначение курса группе
- Макеты экранов: карта роутов и привязка к API
- Шаблоны: ADR, RFC, алгоритм, развёртывание
- Глоссарий проекта
